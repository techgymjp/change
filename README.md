# お釣りピッタリ

レジの値段と財布の中身が毎回出題されます。支払い方を工夫して、**お釣りを受け取った後の財布の硬貨をできるだけ少なく**するWEBゲームです。

- **円バージョン**（1・5・10・50・100・500円玉、千・五千・一万円札）と**ドルバージョン**（1¢・5¢・10¢・25¢、$1・$5・$10・$20 札）
- 全20チャレンジ。そのうち約7割は財布の中身で**ピッタリ払えない**問題です
- 例: 615円のお会計に 1,115円 出せば、お釣りは500円玉1枚だけ
- 毎回、何枚減ったかと最少枚数（全探索で求めた最適解）を表示し、自動で次の会計へ進みます
- 硬貨・紙幣はSVGで描画し、効果音は Web Audio で合成した金属音です（音声ファイルなし）
- 同じ「チャレンジコード」なら同じ20問になるので、友だちと同じ問題で勝負できます（`?cur=JPY&code=ABC123`）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | デザイン |
| `js/core.js` | 出題・お釣り計算・最適解探索（UI非依存。Node でも動作） |
| `js/coins.js` | 硬貨・紙幣の SVG 描画 |
| `js/sound.js` | 効果音（Web Audio） |
| `js/app.js` | 画面制御 |

ビルド不要の静的サイトです。GitHub Pages では「Settings → Pages → Branch: `main` / `(root)`」で公開できます。
